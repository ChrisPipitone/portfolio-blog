Embedded Motor Controller
2024 Firmware C Hardware ↗ GitHub

Motor controllers seem simple until they're not. This one needed to handle encoder dropout gracefully without triggering an E-stop in a way that would take the whole line down.

The interesting problem wasn't the control loop — it was deciding what "graceful" means when you're three layers removed from the person who'll be standing next to the machine.

encoder_controller.c
// Encoder dropout: hold last known velocity for MAX_COAST_MS
if (encoder_valid) {
  velocity = compute_velocity(encoder_delta, dt);
  last_valid_velocity = velocity;
  coast_timer = 0;
} else if (coast_timer < MAX_COAST_MS) {
  velocity = last_valid_velocity * COAST_DECAY;
  coast_timer += dt;
} else {
  trigger_safe_stop();
}

This pattern shows up everywhere in hardware — the question is always about graceful degradation over hard failure. The timeout value matters more than the decay curve.
